一、怎么打开

桌面版（推荐）

双击 勘波 WaveScout.exe 即可运行。无需安装、无需联网、无需运行库，

整个文件夹可以拷到 U 盘或其它电脑直接使用（建议整个文件夹一起拷）。

环境要求：Windows 10 / 11 64 位。

三、平面编辑模式

3.1 导入底图

三种方式任选：

  • 点左侧 「选择平面图图片」
  • 点顶栏 「导入底图」
  • 直接把图片拖进画布

支持 JPG / PNG / BMP / WEBP / GIF。图片超过 4000 像素会自动等比缩小（保证流畅度）。

3.2 标定比例尺 ★ 必做

没有比例尺，热力图的覆盖范围就没有意义。两种方式：

方式 A：按图幅宽度标定（快速）

在左侧「图片宽度」里填入整张图纸的实际宽度（米），点「标定」。

例：图纸宽 1600 px，实际建筑宽 40 m → 填 40。

方式 B：两点标定（准确，推荐）

  1. 点「在图上标定比例尺」
  2. 在图上点击一段已知长度的两端（比如一面 6 米的墙的两头）
  3. 弹窗输入真实米数，确定

标定完成后，左侧会显示 x.xx cm / px，状态变为「已标定」。

画布左下角的比例尺条也会随之更新，可用来核对是否标对。

3.3 画墙 / 门 / 窗

选中工具后，按住左键拖出一条线段，松开即完成。

四种材质的穿透损耗按 2.4G / 5G 分别设定（数值参考 TP-LINK 官方规划工具的实测预设）：

工具2.4 GHz5 GHz厚度适用
砖墙4 dB7 dB120 mm普通砖砌隔墙、轻质隔墙
混凝土25 dB30 dB240 mm承重墙、剪力墙、立柱
玻璃窗8 dB10 dB80 mm普通玻璃、彩钢玻璃幕墙
木门3 dB4 dB40 mm木门、玻璃门、普通门洞
混凝土墙 25 dB 是个很大的数字——一堵混凝土墙基本就能把一个房间的信号拦死，
这是符合实测的。方案阶段看到这种墙，要么绕开，要么在墙两侧各放一个 AP。

小技巧：

  • 自动吸附：端点会自动吸到已有墙的端点 / 交点 / 墙上（默认 8 px，滑条可调 0 ~ 16 px，详见 3.4）
  • 直线修正：接近水平 / 垂直时会自动拉直（默认偏差 9.1° 以内，可调到 0 ~ 17.7°），手抖也能画出直墙
  • 边缘滚屏：画线时把鼠标拖到视图边缘 56 px 内，视图会自动平移，长墙可以一条画到底
  • 强制正交：按住 Shift 拖拽，无条件锁定水平 / 垂直（不受开关影响）
  • 调整已画的墙：点中墙段后拖动两端的蓝色圆点，可以单独移动某一端；拖中部则整体平移
  • 吸附不会把墙拽歪：一旦进入正交（偏差小于设定角度，或按住 Shift），吸附目标必须同时落在

水平 / 垂直线上——撞到垂直墙时端点会精确吸在交点上，墙仍然是平的。

代价是：贴着一条「平行但不同高」的墙时两者无法兼得，此时正交优先、不吸附；

确实要吸那条墙，先把「直线修正」滑条拖到最左（0）或关掉开关。

  • 逐个调整：点中任意墙段，右侧面板可分别改这两个频段的衰减值和厚度（毫米）
  • 墙的厚度只影响显示，衰减按设定的 dB 值计算
「工具」下方有三个开关：端点吸附 / 直线修正 / 边缘滚屏，默认全部开启，随时可关。
开关下面还有两条强度滑条：向左减弱、向右增强，拖到最左端 0 就等于完全关掉该项效果；
滑条位置会记住，下次打开沿用。
关掉后行为与旧版一致（不吸附、只认 Shift 正交、不自动滚屏），设置会自动记住。

3.4 墙体吸附（端点 / 交点 / 墙线）

画墙或拖端点时，只要目标落在吸附强度范围内（默认 8 px，滑条可调 0~16 px，0 = 完全关闭），

就会自动贴到最近的已有墙体上。按优先级依次尝试三种目标：

优先级目标适用场景画布标记颜色
①已有墙的端点折线连续、几段墙共用同一个顶点蓝
②当前走向与已有墙的交点想把墙正好停在另一堵墙上（不改变墙的方向）琥珀
③已有墙上的垂足（最近点）两墙平行、没有有效交点时绿

为什么要有"交点"这一档？因为直接投影到墙上（垂足）会把墙拽歪；

按延长线求交则是保持你画的方向，只把端点顶到墙上——这才是"不多不少正好接上"。

两条硬约束，避免吸到不该吸的地方：

  • 交点必须真的落在已有墙那一段的范围内，不会吸到墙延长线的空中；
  • 交点必须在起点的正方向，不会把墙拉到反方向去。

配套：

  • 吸附强度滑条：最左 0 = 关闭，正中间 8 px = 默认手感，往右更粘（最大 16 px）
  • 「墙线吸附」开关关掉后只吸端点，不再贴墙线
  • 画布上：淡色小方框 = 附近能吸的端点；彩色圆圈 + 十字 = 已吸住的目标；虚线连到光标
  • 拖已有墙的端点时同样生效，歪墙可以直接拖到另一堵墙上对齐
⚠️ 吸附只是把坐标对齐，不会在两堵墙之间建立拓扑绑定关系。
之后单独拖动其中一堵墙，另一堵不会跟着动。

3.5 墙体厚度与衰减（自动 / 手动）

新建的墙默认是自动模式：穿透损耗 = 材质衰减率 × 厚度。

材质每米衰减（2.4G / 5G）120mm 时240mm 时
砖墙33 / 58 dB/m4 / 7 dB8 / 14 dB
混凝土104 / 125 dB/m12.5 / 15 dB25 / 30 dB
玻璃窗100 / 125 dB/m12 / 15 dB24 / 30 dB
木门75 / 100 dB/m9 / 12 dB18 / 24 dB
  • 改厚度，衰减立刻跟着变，不用再手算
  • 想自己指定数值，点属性面板里的「按厚度自动计算」切成手动，两个频段可分别填
  • 打开老项目时：原来就贴着预设值的墙自动转为自动模式，手改过的保持手动，不会把你的数据冲掉

3.6 米制网格

左侧「图层」里可以打开米制网格，淡蓝色的网格线按真实米数绘制，

每 5 格一条加粗线，用来目测空间尺寸是否合理。

四、楼栋与楼层

一个项目可以有多栋楼，一栋楼可以有多层。左侧栏最上方的「楼层」区块用来管理这些层级。

4.1 结构

项目（整个 .wssurvey.json 文件）
├── A 栋
│   ├── 1F   ← 一层图纸 + 这一层的墙、AP、标定
│   └── 2F
└── B 栋
    └── 1F

每一层都是一个独立的平面：自己的底图、比例标定、墙体、AP、覆盖率统计。

切换楼层时，画布、属性面板、统计、热力图全部跟着换到那一层。

层级之间共享的只有：项目名、文件本身。**射频设置（区域 / 频段 / 信道 / 频宽 / 门限 / 层高）

在新增楼层时会从当前楼层复制一份**，之后各层独立可改——方便"整栋统一用 5G Ch.36，某层单独调"。

4.2 怎么用

操作位置说明
切换楼层「楼层」下拉立即切换，画布与统计一起换；每层的撤销记录独立保存，切回来还能继续撤销
新增楼层＋ 楼层接续上一个层号（1F → 2F），空白图纸，需要重新导入本层图纸并标定比例
新增楼宇＋ 楼宇自动建一栋并带一层 1F
重命名重命名改当前楼层的名字（3F / 机房层 / 屋面…），最多 16 字
删除删除删除当前楼层及其全部内容，会先弹确认框；每栋至少保留一层
新增的楼层是空白的：底图、标定、墙体、AP 都不继承。
这是刻意的——楼上楼下的图纸不同，复制几何会产生错位的假数据。

4.3 数据存哪、怎么兼容

  • 保存的项目文件是 v2 结构（buildings[{floors:[...]}]），一个文件装下整栋楼。
  • 旧版（v1）项目文件可以直接打开：自动包成「A 栋 / 1F」，原来的项目名提升为文档名，

墙体、AP、底图、标定、信道设置全部原样保留，不需要手动处理。

  • 反向不兼容：v2 文件不能被 1.7.2 及更早版本打开（旧版不认识 buildings 字段）。

六、框选与批量编辑

一次要改很多墙体或很多 AP 时，不必再一个个点。

6.1 怎么框选

按住 Ctrl 在画布上拖出一个矩形，松手即生效。

类型限制（重要）：框选只会选中「当前模式对应的那一类对象」，另一类即使整个落在框里也会被忽略——

当前模式框选能选中框选不会选中
平面编辑墙体 / 门 / 窗 / 立柱（统一按"墙体"处理）AP
设备编辑AP墙体、门窗
为什么要限制？墙体和 AP 的批量操作完全不同（墙体改材质、AP 改安装方式与功率），
混在一起选很容易改错对象。切换模式时选择集也会自动清空。

框选过程中，矩形左上角和底部提示条会实时显示「仅框选墙体 · 已覆盖 3 段」，

明确当前在选什么类型、已经选中多少，不会出现"不知道选了什么"的情况。

6.2 和点击选择共存

操作结果
普通单击单选（与原行为一致）
Ctrl + 单击（不拖动）单选
多选后单击已选中的其中一个收起为单选，和常见设计软件一致
多选后拖动其中任意一个整体平移这一批对象
Esc取消框选

6.3 批量面板

选中多个对象后，右侧属性栏会自动切换成「批量编辑」面板：

对象可以批量做什么
墙体改材质（砖墙 / 混凝土 / 玻璃窗 / 木门 / 自定义，同时重置该材质的衰减与厚度）、删除、整体平移
AP改安装方式（吸顶 / 壁挂 / 面板）、改发射功率、全部启用 / 停用、删除、整体平移
  • 删除：按 Delete，或点面板里的「删除这 N 段 / 删除这 N 台」
  • 一次批量操作只记一条历史，Ctrl+Z 一次即可整体撤销
  • 框错了按 Esc，或点面板里的「取消框选」

七、热力图与色阶

7.1 颜色

信号由强到弱，颜色依次递减：

颜色强度档RSSI 范围业务含义
🔴 红极强≥ -50 dBm满速率，适合高密场景
🟠 橙强-50 ~ -60高速率，视频 / 大文件无压力
🟡 黄良好-60 ~ -67常规办公、网页、语音
🟢 绿一般-67 ~ -75可用但速率下降，语音可能不稳
🟣 紫弱-75 ~ -85勉强关联，易掉线
⬜ 淡灰盲区< -85连最弱一档都不到

上表给的是各档的代表色（取档位区间的中点）。实际画面上颜色是连续渐变的：

相邻两档之间平滑过渡，不会出现色块硬边。想判断具体数值，看鼠标左下角的实时读数，

比肉眼比色准。

门限与淡显：门限默认 -65 dBm（2.4G / 5G 分别独立设定），可在左侧「覆盖判定门限」调整。

低于门限的档位仍然会画出来，但颜色变淡，这样你能同时看到"哪里有信号"和"哪里不达标"，

而不是被一刀切掉看不见。

为什么默认 -65 而不是更低？因为 -65 dBm 是业界判断"这个点位能不能支撑正常办公"的常用线，
再低的信号虽然能连上，但速率和稳定性都不够用。TP-LINK 官方工具同样用 -65。

7.2 实时读数

鼠标在画布上移动时，左下角会实时显示：

  • 坐标：该点相对图纸左上角的实际米数
  • 信号：该点的计算 RSSI（颜色跟随色阶）
  • 距离：到最近 AP 的直线距离

7.3 统计指标

右侧「无线参数」下方：

  • AP 数量：当前项目设备总数
  • 有效覆盖面积：RSSI ≥ 门限的面积（m²）
  • 良好覆盖 ≥ -67：达到"黄档及以上"的面积占比 —— 这才是工程上通常说的覆盖达标率
  • 弱信号 / 盲区：低于门限的面积占比

下方色带条显示各档位占总面积的比例。

7.4 拖动时不重算

拖动 AP 或墙体期间，热力图不会实时重算，而是保持上一次结果并整体淡显（表示"这份结果是旧的"）；

松手、位置固定后才重算一次。

这样做的原因很直接：以 2481 × 3508 图纸、115 段墙、6 台 AP 的项目为例，一次草稿质量的计算要 237 ms，

精细质量要 779 ms。拖动时每 70 ms 重算一次，一次拖动累计要烧掉 1.4 秒以上的 CPU，画面还一直在抖。

改成"松手才算"之后，拖动本身是 0 计算，跟手度明显提升。

看到热力图变淡 = 位置改过了、结果还没更新，松手就会恢复。

7.5 同频重叠（信号重叠图层）

勾选「图层 → 信号重叠」后，画布上会用黑色边框 + 45° 斜线标出同频重叠区。

判定是逐点做的，满足以下两条才算重叠：

  1. 该点被 ≥2 台 AP 覆盖，且这些 AP 在该点的信号都 ≥ 干扰阈值（默认 -67 dBm）；
  2. 这些 AP 中至少有一对，占用频率区间相交。

由此得到几个直接结论：

情况是否算重叠
两台 AP 同信道，交叠处两边都 -55 dBm✅ 算
一台 -40 dBm、另一台已衰减到 -70 dBm❌ 不算（弱的一侧低于阈值）
两台 AP 不同信道、频段不相交（Ch.36@20M vs Ch.44@20M）❌ 不算
中心信道不同但频带交叠（Ch.36@80M vs Ch.44@20M）✅ 算

左下「重叠判定阈值」滑块可调（-80 ~ -50 dBm）：调低 → 重叠区变大，调高 → 更严格。

图层打开后，左侧会显示重叠面积与轮廓处数；图例里也会多出一行「同频重叠」。

计算用的是独立的中等分辨率网格（约 4.5 万格），因为重叠是"区域"概念，不需要热力图那样的精细度，
这样打开重叠层只多花约 0.1~0.2 秒。

八、计算模型

RSSI = 发射功率 + 天线增益 + 方向图相对增益 − 路径损耗 − 穿墙损耗

① 路径损耗（室内对数距离模型）

PL(dB) = 10·n·lg(d) + 20·lg(f) − 27.55

n 为环境衰减指数，默认 2.4 GHz 取 2.8、5 GHz 取 3.1（切换频段时自动跟随，手动调过则不再自动改）：

场景n 取值
开阔办公、大厅2.6 ~ 2.9
多隔断办公、教室3.0 ~ 3.4
密集货架仓库、机房3.5 ~ 4.0

② 天线方向图

  • 垂直面：按半功率波瓣宽度建模为 cos^n，n 由 HPBW 反解；吸顶天线峰值朝正下方，壁挂 / 面板按设定的下倾角
  • 水平面：全向视为常数；定向按 cos^n 前后分离，后瓣按前后比压制
  • 三种安装方式的差别即由此体现

③ 穿墙损耗

AP 到每个计算点的连线与每段障碍物做线段求交，命中的衰减值累加，

2.4 GHz 与 5 GHz 各取各的衰减值（不再用统一系数换算）；单点损耗上限 80 dB。

④ 多 AP 合并

取各 AP 计算结果的最大值（不做同频干扰、负载、MIMO 增益的处理）。

⚠️ 模型边界

这是工程估算模型，用于方案阶段的 AP 点位、数量、朝向评估，以及给客户做覆盖示意。

它不模拟多径反射、菲涅尔区、人体遮挡、金属货架散射、同频干扰。

最终覆盖效果必须现场实测验证（建议用 Ekahau / NetSpot 或专业扫频工具做后验证）。

十一、常见问题

Q：双击 启动.vbs 没反应？

A：多半是被安全软件拦了。直接双击 index.html，或右键 启动.vbs → 打开方式 → Microsoft Windows Based Script Host。

Q：热力图一片红，是不是算错了？

A：红 = 信号很强（≥ -50 dBm），AP 正下方本来就是 -30 ~ -45 dBm。看"良好覆盖占比"更有意义。如果整层都红，说明 AP 布得太密，可以拉开间距再观察。

Q：热力图没有覆盖到房间角落里？

A：正常。角落被两堵墙同时遮挡时会形成楔形盲区，这正是要看的重点。可以移动 AP、改变朝向，或改用壁挂 / 面板 AP 补盲。

Q：墙的厚度要填多准？

A：厚度只影响显示宽度，衰减由 dB 值决定。四种预设已经按实测填好：砖墙 4/7、混凝土 25/30、玻璃窗 8/10、木门 3/4（前一个是 2.4G，后一个是 5G）。只有遇到特殊材质（比如金属货架、防爆墙）才需要手动改，那种情况建议直接填 30 dB 以上。

Q：为什么我的热力图有大片浅色？

A：浅色 = 有信号但低于门限（默认 -65 dBm），也就是"连得上但不好用"。要看的是深色（达标）区域够不够。如果浅色比例很高，说明 AP 数量不够或位置不对。

Q：能不能做多楼层？

A：当前版本按单层平面计算。上下层干扰建议单独建项目或用不同楼层名分别保存。

Q：图纸是 CAD 导出的 PDF 怎么办？

A：先把 PDF 页面导出成 PNG / JPG（截图或"另存为图片"），再导入本工具。

重新打包

改了 js/ 下的代码后，桌面版不会自动更新，需要重新打包：

npm install            # 首次
npm run build          # 目录版 → dist/          约 3 秒
npm run build:portable # 单文件版 → dist-build/    约 4 分钟（最高压缩）
node_modules/ 只是构建期依赖，分发时不需要，可以删掉（不影响已打好的 exe）。

两个版本怎么选

目录版（dist/）单文件版（dist-build/）
形态exe + 一批 dll + resources 文件夹一个 exe
体积目录 269 MB单文件 74 MB（内部仍是 230 MB）
分发必须整个目录打包压缩后传直接发这一个文件
启动双击即开双击后先自解压到 %TEMP%，首次约 2~5 秒，之后走缓存
适合自己本机固定使用发给同事、放 U 盘、临时换机器

单文件版的原理：exe 本身是个自解压包，运行时把内部 230 MB 解到

%TEMP%\WaveScout-<版本号>\ 再启动。

退出时会自动清掉这个目录里的文件。这么做是为了两件事：一是别白占 230 MB，

二是下次启动不会撞上被占用的旧文件（那会导致解压失败）。

因此：

  • 每次启动都要解压，约 3~5 秒，这是单文件形态的固定代价；想要秒开就用目录版
  • 不要同时开两个实例（第二个会激活已有窗口）；也别在程序运行时手动删那个临时目录
  • 程序被强制结束（任务管理器结束进程、蓝屏）时来不及清理，会留下完整的一份 230 MB，

下次启动会覆盖它；想手动清理，删 %TEMP%\WaveScout-* 即可

  • Windows 有时会短暂占用目录句柄，导致退出后残留一个空目录（里面没有文件，不占空间），

下次启动会复用它，不影响使用

  • 不要把 exe 放在只读介质上运行（如刻录光盘）
  • %TEMP% 所在磁盘需要至少 300 MB 空闲
